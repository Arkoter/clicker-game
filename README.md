# 🎮 Clicker Game

A modern and addictive clicker game with an elegant interface and smooth animations. Click, upgrade, and become the clicking master!

![Version](https://img.shields.io/badge/version-0.1.5-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

## ✨ Features

- 🎯 Modern and responsive user interface
- 💰 Point system with automatic formatting (K, M)
- ⚡ Automatic points per second
- 🌟 Multiple unique upgrades
- 💾 Automatic progress saving
- 🎨 Smooth animations and visual feedback
- 📱 Mobile and desktop compatible

## 🎮 How to Play

1. Click the coin to earn points
2. Use your points to purchase upgrades
3. Upgrades increase your click gains and automatic points
4. Your progress is automatically saved
5. Come back anytime, your progress is preserved!

## 🛠️ Technologies Used

- HTML5
- CSS
- JavaScript
- LocalStorage

## 💻 Installation

1. Clone the repository:
```bash
git clone https://github.com/Arkoter/ClickerGame.git
```

2. Open `index.html` in your browser

That's it! No additional dependencies or installation required.

## 🎨 Customization

You can easily customize the game by modifying:

- `styles.css` to change the appearance
- `script.js` to adjust game values
- Replace `coin.png` with your own click image
